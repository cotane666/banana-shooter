# 🍌 BANANA SHOOTER 2D — пиксельный сайд-скроллер

Отдельная 2D-версия оригинального 3D-шутера. Собирается в **один HTML-файл**,
работает офлайн, без установки и без интернета.

```
cs3d/
├─ banana-shooter-2d.html   ← собранная игра (открыть двойным щелчком)
├─ build2d.ps1              ← сборка
└─ src2d/
   ├─ 01-data.js            ← таблицы из оригинала (оружие, зомби, боссы, снаряжение)
   ├─ 02-audio.js           ← синтезатор звука из оригинала (WebAudio, без файлов)
   ├─ 03-core.js            ← пиксельный канвас, битмап-шрифт, ввод (клавиатура/мышь/тач)
   ├─ 04-world.js           ← 10 карт в 2D, коллизии AABB + пространственная сетка
   ├─ 05-render.js          ← камера, полосатое небо, ступенчатый параллакс, блоки
   ├─ 06-art.js             ← рисование солдата, зомби и силуэтов оружия
   ├─ 07-fx.js              ← частицы, кровь, следы, всплывающие числа
   ├─ 08-weapons.js         ← стрельба, снаряды, ближний бой, луч, взрывы
   ├─ 09-enemies.js         ← зомби, ИИ, мини-боссы, боссы, способности
   ├─ 10-ui.js              ← пиксельный интерфейс: HUD, магазин, пауза, меню
   ├─ 11-game.js            ← цикл игры, волны, экономика, урон, режимы
   ├─ shell.html, style.css
   └─ (сборка: 01-data + 02-audio + 03..11 + shell)
```

## Запуск

Двойной щелчок по `banana-shooter-2d.html` — или:

```powershell
start .\banana-shooter-2d.html
```

Пересборка после правок:

```powershell
powershell -ExecutionPolicy Bypass -File .\build2d.ps1
```

Отладочные параметры в адресной строке:

| Параметр | Что делает |
|---|---|
| `?auto=1` | пропустить загрузочный экран |
| `?play=1` | сразу начать забег |
| `?demo=1` | демо: игрок сам бегает и стреляет, все стволы выданы бесплатно |
| `?shop=1` | открыть магазин (вместе с `demo=1`) |

## Управление

**ПК:** `A`/`D` — идти · `Shift` — бег · `S`/`Ctrl` — присесть · `Пробел`/`W` — прыжок ·
мышь — прицел · `ЛКМ` — огонь · `ПКМ`/`Q` — второе действие · `1` `2` `3` — слоты ·
`E` — сменить ствол · `R` — перезарядка · `B` — магазин · `Esc` — пауза.

**Телефон:** слева — джойстик (вверх = прыжок, вниз = присесть, до упора = бег),
справа — стик прицела; кнопки ОГОНЬ / ПРЫЖ / ВНИЗ / ЗАРЯД / СМЕНА / ЗАЛЕЗ.
Автоприцел включается в паузе.

## Что перенесено из оригинала без изменений

- **Все 40+ стволов** с их уроном, темпом, магазином, разбросом, отдачей,
  падением урона, множителем в голову, снарядами и взрывами (`WEAPONS`).
- **Все типы врагов**: 6 базовых, летун, робот-зомби, 5 мини-боссов, 4 босса
  и финальный МОЗГ-ПОЖИРАТЕЛЬ — с их здоровьем, скоростью, бронёй и способностями
  (`ZOMBIES`).
- **Снаряжение** (`GEAR`), категории магазина, множители сложности.
- **Весь звук** — тот же WebAudio-синтезатор: выстрелы по типам, попадания, кровь,
  смерть, шаги, перезарядка, покупка, взрывы, музыка волн и боссов (`Audio3D_SFX`).

## Что написано заново под 2D

Рендер (canvas 2D, всё в логическом буфере и выводится nearest-neighbor),
физика (клеточная, как в Pixelwreck), ИИ зомби, 10 карт, параллакс, частицы,
интерфейс и битмап-шрифт с обводкой (кириллица рисуется пиксельными глифами).

## Разрушаемый мир с физикой (как в Pixelwreck)

Уровень растеризуется в сетку клеток **8×8** (`03b-destruct.js`). Любая клетка
выбивается выстрелом или взрывом, воронка остаётся на месте. Дальше работает физика:

| Материал | Осыпается | Особенность |
|---|---|---|
| земля, песок | да | песок скользит по диагонали и растекается |
| кирпич, бетон, пол, крыша, стекло, дверь | да | **здания обрушаются**, если подрубить основание |
| дерево, ящики, бочки | да | бочки цепно детонируют |
| камень, металл, платформы, рамка карты | нет | пробиваются, но держат форму |

Реализация как в первой 2D-игре: **список активности** — обрабатываются только
клетки, потерявшие опору, плюс фоновый обход карты, гарантирующий, что ничего
не останется висеть в воздухе. Рендер идёт в offscreen-текстуру карты,
перерисовываются только изменённые клетки, поэтому 50 000 клеток стоят почти ничего.

## Отладка

| Параметр | Что делает |
|---|---|
| `?turbo=1&sec=N` | синхронно прогоняет N секунд игры и печатает отчёт (автотест) |
| `?fast=1` | короткая пауза между волнами |
| `?demo=1` | игрок сам бегает и стреляет, все стволы выданы |

Ошибки кадра выводятся красной строкой прямо в игре — из-за исключения игра
больше не может «зависнуть».

## Детализация

- **Террейн** рисуется 8×8-клетками с фактурой под каждый материал: кирпич с
  расшивкой швов, металл с заклёпками и блеском, стекло с бликом, дерево с
  волокнами, бетон с крапинами, порода с гранями, бочки с жёлтой полосой.
  Открытые края воронок затеняются — провалы выглядят объёмно.
- **Персонажи** рисуются списком прямоугольников в два прохода: сначала тёмный
  силуэт на 1px больше, потом заливка. Получается честный пиксельный контур,
  персонаж читается на любом фоне. У зомби — сутулая поза, открытая пасть,
  светящийся глаз, раны-подтёки при низком здоровье; у игрока — шлем, бронежилет,
  ремень, сапоги, руки ступенчатой «лестницей» к прицелу.
- **Фон**: полосатое небо, солнце/луна, облака с собственным параллаксом,
  три слоя ступенчатых гор и дальний силуэт города с окнами.
- **Эффекты**: гильзы, дым из ствола, осколки породы при разрушении, кровь с
  декалями на земле, ударные волны, вспышки, трассеры.

## Зомби ломают блоки

У каждого типа есть `breakPower` из таблицы оригинала. Зомби, упёршийся в
препятствие, **прогрызает** его: выбивает окружность радиусом `5 + breakPower×4.5`
и лезет дальше. Боссы грызут быстрее и шире (×2.4), мини-боссы ×1.6. Удар зомби по
игроку тоже крошит землю под ним. Это заодно решило проблему «зомби застрял за
стеной» — теперь он просто проедает себе путь.

## Бур

Два новых инструмента в магазине (категория **ИНСТРУМЕНТ**):

| Ствол | Цена | Что делает |
|---|---|---|
| **БУР** | ₽6 500 | роет тоннель радиусом 10px, урон 260/с, бесконечные патроны |
| **ПРОХОДЧЕСКИЙ ЩИТ** | ₽28 000 | тоннель радиусом 20px, урон 820/с, отбрасывает врагов |

Бур работает непрерывно, пока держишь огонь: прогрызает ход в направлении
прицела, крошит породу, отбрасывает зомби и сыпет осколками. Можно копать вниз,
вверх и по диагонали — слот 3 (или 2 для щита).

## Что ещё не сделано

- **Игра по локальной сети** (локальный сервер знакомств + сетевой код) — следующий шаг.
- Полноценные фазовые механики финального МОЗГА (колбы/глаз) — сейчас у него
  общие боссовые способности.
- Часть экзотики упрощена: `РОЙ` пускает самонаводящиеся дроны, `ТЕСЛА` и
  `ЭНЕРГОЩИТ` работают приближённо, лазерная пушка стреляет лучом с перегревом.
- Аим-тренировка, ачивки, скины и аккаунт — не переносились (аккаунт офлайн не нужен).
- ИИ иногда застревает за глухими стенами: нужен 2D-поиск пути (был flow field в 3D).
