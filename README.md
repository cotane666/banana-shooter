# 🍌 BANANA SHOOTER

**3D-шутер от первого лица в браузере**: волны зомби, онлайн-бой на 2–4 игрока,
пять карт и банан за $10 000, который стреляет настоящими летящими бананами со
смешным звуком «боинг».

Работает **на компьютере и на телефоне**. Ничего устанавливать не нужно — один
HTML-файл, внутри которого всё: движок, модели, звуки и сетевой код.

## Режимы

### ПОЛИГОН — тренировка и тест оружия
Всё оружие в магазине **бесплатно** (магазин доступен в любой момент по `B`),
деньги не тратятся. На арене стоят **манекены**, которые не умирают и не
двигаются — над каждым висит табличка с **уроном в секунду**: текущим, лучшим и
суммарным. Удобно сравнивать оружие и проверять взрыв РПГ.

**Аим-тренировка (только на компьютере).** Клавиша `T` открывает **отдельную
комнату**: игрок переносится туда, повторное `T` возвращает назад. В комнате —
разметка дистанций на полу и **мишени на разном расстоянии** (9–34 м, чем дальше —
тем мельче), которые хаотично двигаются, лопаются от попадания и через полсекунды
появляются снова. Очки начисляются за попадание: дальние и мелкие мишени дороже.
В панели считается **счёт**, попадания, точность, текущая и лучшая серия; рекорд
сохраняется между запусками. Манекены и мишени живут в разных комнатах и не
мешают друг другу.

> **На телефоне** панель со счётом, уроном и точностью не показывается, а
> аим-тренировка недоступна — для неё нужен быстрый и точный прицел, который
> пальцем не сделать. Манекены при этом работают: их можно расстреливать и
> смотреть урон прямо над ними.

### ОФФЛАЙН — выживание против зомби
Волны становятся больше и злее. Шесть типов противников:

| Тип | Особенность |
|---|---|
| Ходок | Базовый, медленный |
| Бегун | Быстрый, опасен вблизи |
| Ползун | Низкий, трудно попасть |
| Плевун | Шустрый, среднее здоровье |
| Толстяк | Много здоровья, сильный удар |
| Громила | Босс волны |

За убийства — деньги и очки, в голову дают **×1.5 очков**. Между волнами
передышка и бонус, потом снова магазин. Рекорды сохраняются.

### ОНЛАЙН — бой на 2–4 игрока
Один создаёт игру и получает **код из 5 символов**, остальные вводят его.
Соединение **прямое между браузерами** (WebRTC), сервер нужен только для
знакомства. Раунды как в CS: закупка → бой → результат. Побеждает последний
выживший; раунд заканчивается, когда в живых остаётся один.

**Настройки матча** (в меню онлайна, выбирает хост):

- **Карта** — одна из пяти арен;
- **Игроков в комнате** — 2, 3 или 4;
- **Здоровье игрока** — 50 / 75 / 100 / 125 / 150 / 200 HP.

Хост задаёт параметры до старта, и они автоматически уезжают всем участникам.
Подключается до 4 игроков; лишним игра вежливо сообщает, что комната заполнена.

> Играйте с разных устройств. Если соединение не устанавливается —
> попробуйте другую сеть (мобильную точку доступа вместо Wi-Fi).

#### Игра по локальной сети

Да, по локальной сети играть можно — и это самый надёжный вариант, потому что
трафик идёт напрямую между устройствами и не зависит от интернета.

1. Подключите устройства к **одной сети Wi-Fi** (или к одной точке доступа).
2. Интернет нужен **один раз и ненадолго**: только чтобы браузеры «познакомились»
   через публичный сервер знакомства (PeerJS). Сама игра после этого идёт
   напрямую и интернет ей больше не нужен.
3. Один игрок: **ОНЛАЙН → СОЗДАТЬ ИГРУ**, получает код. Остальные: **ОНЛАЙН →
   ПОДКЛЮЧИТЬСЯ**, вводят код.

Почему нужен хотя бы кратковременный интернет: у игры нет своего локального
сервера, а публичный сервер знакомства размещён в сети. Он только сводит игроков,
но без него устройства не узнают адреса друг друга.

Если интернета нет вообще, вариантов два:
- раздать интернет с телефона (мобильная точка доступа) — устройства будут в
  одной локальной сети и одновременно с интернетом;
- поднять свой PeerJS-сервер в локальной сети и указать его в массиве
  `SIGNAL_SERVERS` в файле `src/11-net.js`.

## Управление

### Компьютер
| Клавиша | Действие |
|---|---|
| `W A S D` | Движение |
| Мышь | Обзор |
| `ЛКМ` | Огонь |
| `ПКМ` | Оптический прицел (AWP / SSG 08) |
| `Shift` / `Ctrl` | Бег / Присед |
| `Пробел` | Прыжок |
| `R` | Перезарядка |
| `1` `2` `3` | Пистолет / Основное / Нож |
| `B` | Магазин (в фазе закупки) |
| `1–9` | Быстрая покупка |
| `Tab` | Счёт (удерживать) |
| `Esc` | Пауза |

### Телефон
- **Слева** — джойстик (появляется в том месте, где коснулись; двойной тап — бег)
- **Справа** — обзор пальцем
- **Огонь** — короткий тап по экрану (отдельной кнопки нет)
- **АВТО** — кнопка справа под большим пальцем: очередь без удержания (как зажатая ЛКМ), повторное нажатие выключает
- **ПРИЦЕЛ / ПРЫЖОК / ПРИСЕСТЬ / МАГАЗИН** — кнопки справа внизу
- **ПЕРЕЗАРЯДКА / СМЕНА / ПАУЗА** — кнопки сверху по центру (чтобы не нажать случайно)
- **ГОТОВ** — в магазине: начать бой, не дожидаясь конца закупки (нужно согласие всех)
- **Автоприцел** — как только прицел оказывается на враге, оружие стреляет само.
  Включается и выключается в настройках («Автоприцел (телефон)»)

В **фазе закупки** движение заблокировано (freeze time) — как в настоящем CS.

## Залезание

Подойдите вплотную к укрытию и **держите движение вперёд** — через пару секунд
игрок подтянется и залезет наверх. Высота не ограничена: забирайтесь на ящики,
контейнеры, крыши зданий, мосты вышек, столбы и даже на 9-метровые стены
периметра. Чем выше поверхность, тем дольше идёт подъём, но он всегда завершится.

Так забраться можно практически куда угодно — используйте это как полноценный
паркур: подошли, зажали «вперёд» — и вы наверху. Сверху отличный обзор, но и
свалиться можно — падение с высоты отнимает здоровье.

Стены нельзя перелезть **насквозь**: если наверху негде встать (узкий парапет без
места для игрока), залезание не сработает.

> Раньше баг был обратным: одно касание стены мгновенно телепортировало игрока
> на её вершину. Теперь это осознанное действие, занимающее время.

приклад, прицел, дульный тормоз и материалы (чёрный полимер, сталь, дерево, олива).

| Категория | Оружие |
|---|---|
| Пистолеты | Glock-18, USP-S, P250, Desert Eagle, R8 Revolver |
| ПП | MP5-SD, P90, UMP-45 |
| Винтовки | Galil AR, FAMAS, AK-47, M4A4, SG 553 |
| Снайперки | SSG 08, AWP |
| Дробовики | Nova, XM1014 |
| Пулемёты | Negev |
| **Тяжёлое** | **МИНИГАН — $10 000 · РПГ-7 — $10 000** |
| **Бананы** | **БАНАН — $10 000** |

### Тяжёлое оружие

**МИНИГАН** — шесть вращающихся стволов. Перед выстрелом раскручивается (0.5 с),
поэтому стрельба начинается не мгновенно, зато темп выше, чем у любого другого
автомата. Магазин на 200 патронов.

**РПГ-7** — ракета с реактивным снарядом и уроном по площади. Прямое попадание
наносит 130 урона, взрыв (радиус 6 м) задевает всех вокруг с ослаблением к краю.
Одноразовый выстрел — 1 ракета в трубе, 6 в запасе. Вблизи опасно для себя.

### 🍌 Банан

Не хитскан! Выстреливает **настоящий банан**, который летит по дуге с гравитацией,
вращается и лопается жёлтыми кусочками при попадании. Звук выстрела — мультяшное
«боинг» с резиновым писком.

Урон 55 (в голову больше), магазин 45, дальность ~120 м. Работает по зомби и по
сопернику в онлайне.

**Скорострельность 900 выстрелов/мин** — это автоматический «бананомёт»: урон за
плод остался прежним (55), но летят они очередями, поэтому вблизи банан сносит
всё. Отдача за выстрел снижена, чтобы ствол не задирался.

## Технологии

- **Three.js** r160 — 3D (вшит в файл)
- **PeerJS** / WebRTC — P2P для онлайна
- **WebAudio** — весь звук синтезируется, ни одного аудиофайла
- **Все текстуры** генерируются процедурно на canvas
- **PWA** — установка на главный экран и офлайн-режим
- **Android WebView** — нативная обёртка для APK

Внешних зависимостей — **ноль**. Один HTML-файл.

### Что внутри

| Система | Реализация |
|---|---|
| Физика | Цилиндр против AABB, скольжение по осям, ступени, гравитация |
| Паркур | Залезание на любую высоту: удержание «вперёд» у поверхности |
| ИИ зомби | Flow field + A* для навигации, проверка видимости, расталкивание |
| Стрельба | Рейкаст по хитбоксам (голова / корпус / ноги), пробитие укрытий |
| Снаряды | Банан с баллистикой, гравитацией и вращением |
| Сеть | Обмен состоянием 34 раза/с, интерполяция, пинг, авторитетный хост |
| Эффекты | Трассеры, кровь, искры, дым, следы пуль, вспышки |
